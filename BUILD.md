# VSTVibe Build Instructions

VSTVibe is a VST3 synthesizer plugin that generates audio from Mandelbrot fractal mathematics.

## Quick Start

### Prerequisites
- Visual Studio 2022 with C++ build tools
- CMake 3.15 or later
- Steinberg VST3 SDK installed at `C:\code\VST_SDK\vst3sdk`

### Building

Use one of these batch scripts from the project root directory:

#### 1. **build.bat** - Standard Build
Configures CMake and builds in Release mode. Use this for normal development.
```cmd
build.bat
```

#### 2. **rebuild.bat** - Clean Rebuild
Removes the build directory and performs a complete rebuild. Use this if you encounter build issues.
```cmd
rebuild.bat
```

#### 3. **clean.bat** - Clean Only
Removes all build artifacts without rebuilding. Use this to save disk space.
```cmd
clean.bat
```

## Build Configuration

The CMakeLists.txt file automatically:
- Sets VST3_SDK_PATH to `C:/code/VST_SDK/vst3sdk` by default
- Validates the SDK location exists
- Links all required VST3 SDK libraries
- Configures compiler options for MSVC

### Customizing VST3 SDK Path

If your VST3 SDK is in a different location:

**Option 1: Modify CMakeLists.txt**
```cmake
set(VST3_SDK_PATH "C:/your/custom/path/vst3sdk" CACHE PATH "...")
```

**Option 2: Set via command line**
```cmd
cd build
cmake -DVST3_SDK_PATH="C:/your/custom/path/vst3sdk" -G "Visual Studio 17 2022" ..
cmake --build . --config Release
```

## Features

- **MIDI Input:** Play notes on your keyboard/MIDI controller
- **Mandelbrot Synthesis:** Audio generated from fractal mathematics
  - Note pitch controls zoom level
  - Velocity controls fractal region offset
- **Real-time Visualization:** GUI displays the Mandelbrot set being synthesized
- **Resizable Window:** Adjust GUI size (300x200 min, 2048x1536 max)

## Output

The compiled plugin is located at:
```
build/Release/VSTVibe.vst3
```

Copy this file to your DAW's VST3 plugin directory:
- **Reaper:** `C:\Program Files\REAPER\Plugins\FX`
- **Bitwig Studio:** `C:\Users\[Username]\AppData\Local\Bitwig Studio\Plugins`
- **Ableton Live:** System VST3 folder or custom path

## Troubleshooting

### CMake Configuration Error
If you see "VST3 SDK not found":
1. Verify the SDK is installed at `C:\code\VST_SDK\vst3sdk`
2. Check that `public.sdk` subdirectory exists
3. Run `rebuild.bat` to reconfigure

### Build Fails
1. Run `clean.bat` first
2. Ensure Visual Studio 2022 is installed
3. Check that no other processes are using the .vst3 file
4. Run `rebuild.bat`

### Plugin Not Loading in DAW
1. Verify the plugin compiled: `build/Release/VSTVibe.vst3` should exist
2. Copy the file to your DAW's VST3 plugin directory
3. Rescan plugins in your DAW
4. Check DAW error logs for issues

## Development

To modify the plugin:
1. Edit source files in `source/`
2. Run `build.bat` to compile
3. Reload the plugin in your DAW

The CMakeLists.txt and build scripts handle all compilation automatically.
